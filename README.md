# Omnex Brand Kit

Official brand assets for Omnex — a Layer 2 blockchain platform.

## 📁 Structure

This repository contains all official brand assets for Omnex. The main logo assets are located within the `assets/logos` directory.

- `assets/logos/wordmark/` - The complete logotype including the "Omnex" name. Recommended for most use cases.  
- `assets/logos/symbol/` - The standalone Omnex icon. Ideal for smaller layouts or where the brand is already recognized.

Each folder includes both `svg` and `png` subdirectories for different file formats.

## 📖 Brand Guidelines

For detailed information on how to properly use our brand assets, including logo placement, color palette, and typography, please refer to our official brand guideline document:

- **[Omnex Brand Visual Guidelines](./guidelines/omnex_brand_visual_guidelines.pdf)**

## 🎨 Logo Files

- **Wordmark**: The full Omnex logo with text. Found in `assets/logos/wordmark/`.  
- **Symbol**: The standalone Omnex mark. Found in `assets/logos/symbol/`.

### Naming Convention

File names are formatted to be descriptive and consistent:

- **Wordmark**: `[background]-[color]-[shape].ext` (e.g., `white-bg-blue-logo-circle.svg`)  
- **Symbol**: `[color]-[shape].ext` (e.g., `blue-circle.svg`)
